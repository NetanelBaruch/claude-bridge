# Changelog

## 0.2.1

Inspect profile now includes the Glob and Grep built-in tools alongside Read, so a read-only task can discover and search files inside the approved working folder. Still no shell, web, or MCP tools in either profile, and restricted mode continues to confine file tools to working directories. No behavior changes to approvals, uploads, or edit profile.

## 0.2.0

Pre-release hardening: explicit task snapshot approval, trusted-workspace requirement, exact author allowlist, restricted CLI tool profiles, disabled customizations/MCP servers, local-first output review, durable checkpoints, cross-window project lock, bounded output and cancellation. No automatic execution or output publication. Initial 0.1.0 prototype is superseded and should not be installed.
